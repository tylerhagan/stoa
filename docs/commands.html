Commands

Type these in chat. Almost all of them also have a control in STOA's settings: /stoa.

/stoa
Open settings.
/stoa unlock
Toggle frame moving.
/stoa reset
Put moved frames back in their default spots, in every role.
/stoa safe
Turn off every skin that touches Blizzard frames (chat, bags and menu, bar art, buttons, windows, tooltips, character sheet, top of screen, nameplates, swing timer, meters, map, quest reward) and reload.
/stoa tooltip cursor
Tooltips at the cursor; /stoa tooltip console puts them back above the console.
/stoa vision
Cycle colour vision modes, or name one: redgreen, blueyellow, nocolour or standard.
/stoa windows reset
Put every moved Blizzard window back in its usual place.
/stoa theme
Cycle the themes (house, Your class, then each class)
/stoa keywords inv, invite
Set auto-invite keywords.
/stoa friends
Open the Company roster (/stoa company too)
/stoa glance
List what At a glance can show; /stoa glance add <name>, remove <name>, reset (/stoa tally still works)
/stoa welcome
Open the welcome wizard again.
/stoa check
Check the spell IDs, game functions and Blizzard frames STOA relies on against this game build.
/stoa report
Your version, game build, spec, theme and screen and UI scale, language, game settings STOA holds, other addons and any errors STOA caught, ready to copy.
/stoa layout
A short line with your frame positions (every role) and look, to share; paste one on the backup page to use it.
/stoa editmode
Switch to STOA's Edit Mode layout for Blizzard's own frames (added for you on a new character; refreshed when STOA ships a newer one). On a narrow screen or a large UI scale STOA uses its compact layout, with the bars stacked under the medallion, and switches back when there's room; /stoa editmode wide keeps the wide one, compact picks the compact one, auto switches by screen again, status says which it wants and why.
/stoa log
Start combat logging now (/stoa log stop ends it, /stoa log test shows the reminder)
/stoa cdm
What the game's Cooldown Manager tracks and which of its values STOA can read (try it in a fight)
/stoa restore
Put back every game setting STOA changed (camera distance, map fade, target plate size, combined bags, proc art), unless you've changed it since.
/stoa addons
List other addons doing one of STOA's jobs and ask again which to keep.
/stoa backup
Copy your settings as text, or paste a backup to restore it.
/stoa xp
Experience this session, per hour, and time to level.
/stoa pull [seconds]
Pull countdown for the group (10 by default); /stoa pull 0 cancels.
/stoa uprank
Put the best rank of each spell on your bars now.
/stoa restock
add <item> [count], remove <item>, list, clear: what this character keeps topped up at vendors.
/stoa alts
Your characters: level, rest, lockouts and gold; /stoa alts forget <name> drops one.
/stoa bind
Hover a button and press a key to bind it (/stoa kb too)
/stoa away
Show the away screen now.
/stoa junk add <item>
Mark an item as junk (link or ID); remove <item>, list, clear.
/stoa loot
Gold an hour and loot value this session; /stoa loot reset starts again.
/stoa trainer
Open Training: spells waiting now and coming next, with prices (/stoa trainer list prints them in chat)
/stoa tray
List the addon icons in the tray; leave <name> keeps one on the minimap, take <name> brings it back.
/stoa copychat
Copy the chosen chat window's last 200 lines.
/stoa preset full
Start from a preset: full, slim, minimal, quiet or classic, then /reload.
/stoa state
Print the current state and role.
/stoa clicks
Edit click-cast bindings for your current role.
/stoa grid
Cycle the click grid: always open, folded until needed, or hidden; or name one: open, fold, hidden.
/stoa test
Show sample party cards without a group; /stoa test raid, raid10 or raid40 for a raid.
/stoa probe
In a fight, print what the game hides from addons right now.
/stoa combat
Practice combat out of combat: the console folds, the Halo, combat bar and group frames take their combat places. Again to end it.
/stoa setups
List the setups your other characters saved; /stoa setups load <number> copies one.
/stoa looks
Which supported addons (Questie, Bagnon, Details, RestedXP) wear STOA's look, and offers it again where declined.
/stoa gallery
Open the widget gallery: every STOA control and surface on one page.
/stoa procs list
What procs your class watches and whether each is known; /stoa procs test shows the proc art and glow.
/stoa auras [ids]
Out of combat, report what the game's aura container can draw, for the given spell IDs.
/stoa timers
Show sample flight and breath timers.
/stoa move
Same as /stoa unlock.

No command matches.
