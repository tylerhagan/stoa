Install

STOA is one folder named Stoa in your AddOns folder. Here is how to get it there, and what to know after.

Install

  • CurseForge app: search for STOA under World of Warcraft, Forever, and install it.
  • By hand: download Stoa-<version>.zip from Releases (or CurseForge) and unpack it into World of Warcraft\_forever_\Interface\AddOns. The zip already holds one folder named Stoa, so there's nothing to rename.
  • From the code: GitHub's "Download ZIP" of the repository unpacks as stoa-main. Rename that folder to exactly Stoa, or the game won't load it.

Then restart the game (not just /reload) the first time, so it picks up STOA's fonts and textures. A welcome page opens on each character's first login; /stoa welcome brings it back.

STOA looks best on an ultrawide (21:9) screen, which it was designed on. On 16:9 or 16:10 it switches to a compact layout by itself; /stoa editmode status shows which layout it picked and why.

Reporting a bug

Open an issue. Type /stoa report in game, press "Select all to copy" and paste it in: it carries your version, class, screen size, other addons and any errors STOA caught. A screenshot helps too.

Forever notes

If a game patch raises the interface number before STOA catches up, the AddOns list shows it as out of date: tick "Load out of date AddOns" there and it loads as before.

Forever runs the modern client, so STOA follows Midnight-era rules: unit values can be secret in combat, and the combat log is closed to addons. STOA never does maths on a value without checking issecretvalue first (see Core/Util.lua), and it skins Blizzard's own data rather than recalculating it. When the game says auras are hidden (C_Secrets.ShouldAurasBeSecret), buff reminders and aura lists stand down rather than reading an empty list as "missing".

Fonts

STOA ships with Tenor Sans for names and numbers and Inter SemiBold (18pt cut) for labels, in Media/Fonts. Both are under the SIL Open Font License; see Media/Fonts/OFL.txt. If a font file is missing, STOA falls back to Cormorant Garamond if present, then the game's own fonts.

A font file that is new to the game is only picked up after a full restart of the game, not a /reload.
