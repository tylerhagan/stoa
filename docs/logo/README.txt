STOA / ESSENCE — production assets

Recreated as clean vector geometry from the supplied #5 Essence reference.

Files
- stoa-essence.svg / .png: gold wordmark, transparent background.
- stoa-essence-dark.svg / .png: gold wordmark on near-black (#0B0C0D).
- stoa-essence-flat.svg / .png: single-color gold (#DDB676), transparent. Use for small sizes, print, or recoloring.
- stoa-essence-symbol.svg / .png: standalone O/horizon symbol, transparent.

Wordmark PNGs: 3072 x 927 pixels, RGBA where transparent.
Symbol PNG: 2048 x 2048 pixels, transparent.
SVGs: scalable paths and ellipse geometry, with no font dependencies, linked images, scripts, or raster content. The gold versions use standard SVG gradients.

Usage
Use SVG whenever supported. Use transparent PNGs on dark surfaces for best contrast. The flat version is the simplest choice at small sizes. Suggested minimum wordmark width: 240 screen pixels; symbol: 32 pixels. Maintain the supplied aspect ratio and clear space.

This is a polished vector reconstruction, not a pixel-exact trace of the raster reference. The lettering and horizon were drawn as editable geometry.
